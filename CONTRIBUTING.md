# Contributing

Thanks for helping. Bug reports, ideas and pull requests are all welcome.

- **Bugs:** open an issue with your macOS version, the Ollama models you have, and what you expected versus what happened.
- **Pull requests:** keep each one to a single change. Run `cargo test` in `app/src-tauri` and `npm run build` in `app` before you open it.
- **New local jobs or tools:** open an issue first so we can agree on the shape.
- **Screenshots:** the README images come from `app/tests/shots/take-shots.mjs`, which runs the real frontend against a mocked backend and a demo project. Retake them after a UI change.
